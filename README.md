# AI for Mere Mortals

Plain-language guides to understanding AI, written for people who want to
actually run it — especially on their own computers at home.

No math degree required. No hype. Just what things are, why they matter,
and how they connect to running models yourself.

## The guides

1. [How LLMs Work](how-llms-work.md) — what a language model actually is,
   in one page. Start here.
2. [Tokens](tokens.md) — the unit everything is measured in: speed,
   memory, and cost.
3. [Reading a Hugging Face Model Page](huggingface-guide.md) — what the
   numbers and labels mean: 7B, Q4_K_M, GGUF, context length, instruct.
4. [Choosing a Model](choosing-a-model.md) — matching a model to your
   hardware and your task.
5. [Running Models at Home](running-models-at-home.md) — RAM math,
   CPU vs GPU, and the settings that matter (Ollama-focused).
6. [RAG and Embeddings](rag-and-embeddings.md) — teaching a model about
   *your* documents.
7. [Glossary](glossary.md) — quick definitions, A to Z.

## A note on language

AI has a habit of sounding complicated on purpose. These guides try to
say the simple thing plainly. If a term appears before it's explained,
check the glossary — and if something's still confusing, that's the
guide's fault, not yours.
